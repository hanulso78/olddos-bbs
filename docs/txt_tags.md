# 화면 파일(txt/) 태그

`txt/` 화면 파일(대문 `top.txt` 등)에 `[태그]` 를 적으면 화면에 보일 때 값으로 바뀐다.
단어 사이는 `_` 로 잇는다. 모르는 이름이나 `[Enter]`, `[가 입 일]` 처럼 태그가 아닌 것은 그대로 나온다.

## 칸 맞춤

printf 처럼 `:숫자` 를 붙이면 그 칸 수에 맞춘다. 길면 자른다 (한글이 반으로 잘리지 않게).

| 쓰기 | 뜻 | 예 (값이 `5560`, `하늘소`) |
|---|---|---|
| `[num_members:8]` | 오른쪽 맞춤 8 칸 | `    5560` |
| `[nick:-12]` | 왼쪽 맞춤 12 칸 | `하늘소      ` |
| `[nick:^12]` | 가운데 맞춤 12 칸 (앞에만 빈칸) | `   하늘소` |

가운데 맞춤을 조건부 표시와 함께 쓰면 문장 전체를 가운데에 놓는다.
예) `[today_quote:^78?오늘의 명언  %s]` : "오늘의 명언  ..." 한 줄을 78 칸 가운데에 (넘치면 명언을 줄임)

## 조건부 표시

`[태그?문장]` 으로 쓰면 값이 비었거나 `0` 일 때는 통째로 빈칸이 되고, 아니면 문장의 `%s` 자리에 값이 들어간다.
가끔만 의미 있는 값(공휴일, 새 쪽지, 생일)에 쓴다. 칸 맞춤과 함께 `[nick:-8?(%s)]` 처럼 쓸 수도 있다.

| 쓰기 | 값이 있을 때 | 없을 때 |
|---|---|---|
| `[holiday?오늘은 %s 입니다]` | `오늘은 추석 입니다` | (빈칸) |
| `[new_memo?새 쪽지 %s통!]` | `새 쪽지 2통!` | (0 이면 빈칸) |
| `[birthdays?오늘 생일: %s]` | `오늘 생일: 하늘소` | (빈칸) |

## 사이트

| 태그 | 값 |
|---|---|
| `[host_name]` | 사이트 이름 (`hanulso.cfg` 의 `<name>`) |
| `[num_members]` | 전체 회원 수 |
| `[num_conns]` | 지금 접속자 수 |
| `[num_articles]` | 전체 글 수 |
| `[today_num_articles]` | 오늘 올라온 글 수 |
| `[uptime]` | 서버 가동 시간 (`12일 3시간`) |
| `[since_days]` | 사이트를 연 지 며칠째 (`hanulso.cfg` 의 `<since>2016-01-01</since>`, 없으면 빈칸) |
| `[online_users]` | 지금 접속 중인 회원 닉네임들 (`, ` 로 이음) |
| `[chat_users]` | 지금 대화방에 있는 사람 수 |

예전 이름 `[hostname]`, `[nummembers]`, `[numconns]`, `[numarticles]`, `[todaynumarticles]` 도 그대로 쓸 수 있다.

## 날짜

| 태그 | 값 |
|---|---|
| `[date]` | `2026-10-05` |
| `[time]` | `21:30` |
| `[weekday]` | `월` |
| `[lunar_date]` | `음력 8월 25일` (윤달이면 `음력 윤2월 3일`) |
| `[holiday]` | 오늘의 공휴일/명절 이름 (`추석`, `한글날` ...). 아니면 빈칸 |
| `[today_quote]` | 오늘의 명언 (`나는 생각한다, 고로 존재한다. - 데카르트`, 날짜마다 하나) |
| `[random_tip]` | 한 줄 도움말 (`txt/tips.txt` 에서 접속할 때마다 하나) |
| `[weather]` | 지금 날씨 (`맑음 13℃`). 지역은 `[weather_place]` |
| `[weather_place]` | 날씨 지역 (`서울`, `성남시`). PE 의 내 지역, 없으면 접속한 곳의 IP 로 짐작, 둘 다 없으면 서울 |
| `[usd_rate]` | 1 달러 환율 (`1,344.09`) |

`[weather]`, `[usd_rate]` 는 바깥 사이트에서 받아 오므로 대문이 기다리지 않도록 뒤에서 받아 둔다
(날씨 30 분, 환율 1 시간마다 `tmp/tag_*.cache`). 서버를 켜고 처음 한 번은 빈칸이다.
IP 로 찾은 지역 (ip-api.com) 은 하루 동안 `tmp/tag_geo_<IP>.cache` 에 둔다. 한국 밖이나 사설 IP 는 서울.

## 통계 (`ST` 와 같은 값)

| 태그 | 값 |
|---|---|
| `[today_visitors]` | 오늘 다녀간 회원 수 (출석 기준) |
| `[max_online]` | 오늘 최고 동시 접속 |
| `[max_online_ever]` | 역대 최고 동시 접속 |
| `[today_members]` | 오늘 가입한 회원 수 |
| `[newest_member]` | 가장 최근에 가입한 회원 닉네임 |

## 최근 내용

| 태그 | 값 |
|---|---|
| `[graffiti]` | 한줄 낙서장 최근 한 줄 (`닉네임: 내용`) |
| `[last_notice]` | 최근 공지 제목 (메뉴에서 `go="notice"` 인 게시판) |
| `[hot_article]` | 최근 7 일 가장 많이 읽힌 글 제목 (누구나 볼 수 있는 게시판만) |
| `[birthdays]` | 오늘 생일인 회원 닉네임들 (`, ` 로 이음) |
| `[hero_champ]` | 용사의 전설 1 위 |
| `[rain_champ]` | 산성비(한글) 최고 점수 (`닉네임 (1234)`) |
| `[last_article]` | 가장 최근 글 (`[자유 게시판] 제목`, 누구나 볼 수 있는 게시판만) |
| `[articles_번호]` | 지금 메뉴에서 그 번호 게시판의 글 수 `(57)`. 하위 메뉴면 그 안의 게시판을 모두 더함. 999 까지는 그대로, 넘으면 `(1k)`, `(12k)`. 게시판이 아니면 빈칸. 메뉴 화면 파일에서 `[articles_5:-5]` 처럼 5 칸으로 쓴다 |

통계와 최근 내용은 접속자가 많아도 DB 를 매번 뒤지지 않도록 60 초 동안 `tmp/tags.cache` 에 캐시한다.
(그래서 낙서를 남기고 대문으로 가도 최대 1 분 늦게 바뀐다)

## 로그인한 회원 본인

로그인한 뒤의 화면에서만 값이 있다. 로그인 전 화면에서는 빈칸이 된다.

| 태그 | 값 |
|---|---|
| `[nick]` | 닉네임 |
| `[user_id]` | 아이디 |
| `[level]` | 등급 이름 (`일반회원`, 운영자는 `시숍`) |
| `[new_memo]` | 안 읽은 쪽지 수 |
| `[streak]` | 연속 출석 일수 (어제나 오늘 출석이 끊기지 않았을 때) |
| `[last_login]` | 지난번 접속 시각 (`2026-10-04 21:05`) |
| `[total_attend]` | 총 출석 일수 |
| `[attend_rank]` | 오늘 몇 번째로 왔는지 |
| `[my_articles]` | 내가 쓴 글 수 (5 분마다 다시 셈) |
| `[member_days]` | 가입한 지 며칠째 |
| `[birthday_dday]` | 생일까지 `D-23`, 당일은 `오늘 생일!` (생일 정보가 없으면 빈칸) |
| `[ddi]` / `[zodiac]` | `말띠` / `전갈자리` |
| `[my_fortune]` | 내 띠의 오늘 운세 한 줄 (`GO FORTUNE` 과 같은 내용) |

## 어디서 쓸 수 있나

- `[host_name]`, `[num_*]`, `[today_num_articles]`, `[uptime]`, `[date]`, `[time]`, `[weekday]` 는
  화면 파일을 보여 주는 모든 프로그램에서 바뀐다.
- 나머지는 BBS 본체(`bin/main`)가 보여 주는 화면에서만 바뀐다.
  가입(`guest`)/비밀번호 찾기(`pass`) 화면 같은 다른 프로그램에서는 태그가 그대로 보인다.

## 24 줄 화면용 파일

BBS 는 로그인할 때 터미널에 커서 위치를 물어(`ESC[6n`) 화면 줄 수를 알아낸다.
같은 이름 끝에 숫자를 붙인 파일이 있으면, 그 숫자가 그 파일이 쓰는 화면 줄 수다.
화면에 들어가는 것 중 가장 큰 것을 보여 준다 (숫자가 없는 파일은 25 줄).

| 파일 | 언제 |
|---|---|
| `txt/top24.txt` | 24 줄 (위치를 알려 주지 않는 터미널도 24 줄로 본다) |
| `txt/top.txt` | 25 ~ 27 줄 |
| `txt/top28.txt` | 28 줄 이상 (이야기 윈도판 등): 오늘의 명언, 한 줄 도움말이 더 있음 |

대문 다음에 빈 줄 하나와 프롬프트 2 줄이 이어서 나온다 (`footer.txt` 는 비어 있음).
지금은 `top24.txt` 는 19, `top.txt` 는 20, `top28.txt` 는 23 번째 줄까지 쓰고,
각 파일 끝에서 커서를 그 다음 줄(빈 줄)로 옮겨 두어 프롬프트가 한 줄 떨어져 나온다.

## 예

```
 [host_name] 에 오신 것을 환영합니다, [nick] 님!   [date] ([weekday]) [lunar_date] [holiday]
 회원 [num_members:5]명 / 접속 [num_conns:3]명 / 오늘 다녀간 회원 [today_visitors]명
 새 회원: [newest_member]   낙서: [graffiti]
```
